# Spree Reviews

This is a Reviews extension for [Spree Commerce](https://spreecommerce.org), an open source e-commerce platform built with Ruby on Rails.

## Installation

1. Add this extension to your Gemfile with this line:

    ```ruby
    gem 'spree_reviews', github: 'laaichiu/spree_reviews'
    ```

2. Run the install generator

    ```ruby
    bundle exec rails g spree_reviews:install
    ```

3. Restart your server

  If your server was running, restart it so that it can find the assets properly.
